## Review protocol when sources are restored

For each PDF, render every page and record: page dimensions, header hierarchy, boxed rules, example/exercise labels, density, columns, formula separation, table/graph placement, blank work space, part labels, calculator/exactness language, and source role. Pair questions with official solutions before deriving answer forms. For screenshots, preserve chronological groups, inspect original resolution, and link each image to a source segment before using it for generation.

## Source-to-interface hypotheses requiring owner/source approval

These are product-spec hypotheses, not source findings:

- Use generous worksheet-like whitespace around the active problem.
- Preserve tables, graphs, and multipart information order rather than converting everything to prose.
- Separate source context from the solving area.
- Show one learning state at a time.
- Use source-pattern badges only after a construction is verified.

No color, font, border, spacing, or page-density choice is attributed to the professor's materials until visual review occurs.
