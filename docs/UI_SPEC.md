# UI Specification

## Question screen

Persistent header:
- chapter/section;
- family;
- mode;
- timer when applicable;
- source-pattern badge (not the answer source).

Main panel:
- faithful question rendering;
- table/graph/formula support;
- math answer field;
- optional scratch steps.

Recognition drawer:
- family choice;
- clue selection;
- first-decision choice.

Feedback panel:
- result;
- exact error category;
- source-linked connection explanation;
- comparison problem showing one changed feature.

## Visual learner requirements

- side-by-side “lecture form” and “assessment form”;
- highlighted invariant structure;
- color-independent labels and icons;
- expandable step flow;
- tables and number lines where relevant;
- minimal scrolling per question;
- preserve full train of thought in review rather than reducing it to a short summary.

## Exam mode

- no family label;
- no clues;
- no immediate feedback;
- question navigation;
- flag for review;
- final review screen;
- separate scoring by content and critical-check errors.
