# Development Roadmap

1. **Delivered baseline:** audit, four inferred seed families, staged paper-first loop, equivalence validation, local attempts, bounded feedback, retry, and evidence display.
2. **Source review:** ingest actual binaries, issue stable IDs, visually inspect pages, replace inferred constructions, and resolve pairings.
3. **Content depth:** three source-backed constructions and validators per priority family.
4. **Adaptive mastery:** review queue and delayed-transfer scheduling.
5. **Strict assessment:** Professor Mode and source-backed builders.
6. **Next-Line Coach:** branch-aware step graphs for a limited reviewed family set.

No phase is complete merely because a directory or placeholder exists.
