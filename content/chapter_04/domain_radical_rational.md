# Purpose

Learn to recognize and intersect the two restrictions created when an even-index radical appears in the numerator and a variable expression appears in the denominator.

# Professor Surface Construction

The user supplied the representative construction “Find the domain of” followed by a function of the form $f(x)=\frac{\sqrt{ax+b}}{cx+d}$. Exact professor-source wording remains pending until the referenced worksheet or test binary is available.

# Underlying Mathematical Structure

The radicand must be nonnegative and the denominator must be nonzero. The domain is the intersection of those restrictions, written in interval notation.

# Lecture Form

State and solve $ax+b\ge 0$, then state and solve $cx+d\ne0$.

# Assessment Form

Identify both restrictions without being told which operations create them, intersect the results, and present the domain in interval notation.

# Hidden Prerequisites

Linear inequalities, linear equations, interval notation, included versus excluded endpoints, and set intersection.

# Recognition Clues

The prompt asks for a domain; the formula contains an even radical and a denominator with the variable.

# First Decision

Write the radical restriction $ax+b\ge0$ before simplifying or inspecting candidate values.

# Decision Path

```text
recognize both restriction-producing operations
→ solve the radicand inequality
→ solve the denominator exclusion
→ intersect the restrictions
→ write and verify interval notation
```

# Restrictions and Required Checks

The radical endpoint is included when it does not make the denominator zero. Every zero of the original denominator is excluded, even if algebraic simplification would hide it.

# Variation Dimensions

Safely vary positive coefficients, integer boundary points, the position of the denominator zero relative to the radical boundary, function/variable names, and guidance density. Do not allow the denominator to be identically zero or the radical and denominator restrictions to disappear accidentally.

# Difficulty Ladder

## L0 Foundation

## L2 Guided

## L3 Representation Change
Read one restriction from a graph or number line and the other from the formula.

## L4 Mixed Prerequisite
Solve both restrictions when signs or non-unit coefficients require algebra first.

# Common Errors

Ignoring the denominator; requiring the radicand to be strictly positive; excluding the radical endpoint unnecessarily; unioning rather than intersecting restrictions; or failing to split an interval around an excluded point.

# Professor Traps

The denominator zero may fall outside the radical interval and require no visible split, or it may fall inside and require two intervals. Exact professor-supported traps remain pending binary review.

# Professor-Style Templates

1. Find the domain of $f(x)=\frac{\sqrt{ax+b}}{cx+d}$ with the denominator zero below the radical boundary.
2. Find the domain with the denominator zero inside the allowed radical interval, forcing a split.
3. Present the same invariant structure with a different function name, coefficients, and reduced guidance in cumulative review.

# Feedback Rules

First ask which operation creates each restriction. If one is missing, reteach only that rule. Do not reveal the interval intersection until both restrictions are stated.

# Expected Answer Presentation

Interval notation with a closed radical endpoint when allowed and an open split at every denominator zero.

# Mastery Rule

Require correct recognition in at least three surface forms, two independently solved variants including an internal denominator exclusion, no endpoint or domain errors, and delayed timed transfer.
