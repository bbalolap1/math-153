# Purpose

Lecture 2.1 develops equation solving and explicitly distinguishes identities, contradictions, and conditional equations. Quiz 1 and Test 1 then remove much of the scaffolding and require the algebra to be shown.

# Professor Surface Construction

The assessment sources place distribution, fractions, radicals, and absolute-value notation around the equation, so the solver must classify the equation before choosing reversible operations.

# Underlying Mathematical Structure

Undo operations while preserving equality.

# Lecture Form

A direct single-decision example with the relevant notation already visible.

# Assessment Form

A minimally guided prompt that requires recognition, a first decision, handwritten work, and a complete answer.

# Hidden Prerequisites

constants and signed-number arithmetic.

# Recognition Clues

Use the operation and notation in the prompt, not merely its vocabulary, to identify the family.

# First Decision

Undo operations while preserving equality.

# Decision Path

```text
recognize the invariant structure
→ choose the first reversible or evaluative action
→ complete the algebra on paper
→ verify restrictions and requested form
→ present the answer
```

# Restrictions and Required Checks

Recheck the result in the original prompt. Apply domain restrictions whenever an operation requires them.

# Variation Dimensions

Change one controlled dimension at a time: coefficients, notation, representation, then prerequisite mixture. Use only variations supported by the attached lecture and assessment sources.

# Difficulty Ladder

## L0 Foundation
Repair constants and signed-number arithmetic in isolation.

## L1 Direct
Solve the direct symbolic form with a single decision.

## L2 Guided
Classify the family and select the first decision before solving.

## L3 Representation Change
Use a table, verbal statement, or alternate notation when source-supported.

## L4 Mixed Prerequisite
Combine the family with one older algebra skill.

## L5 Professor Style
Use the information order and guidance density visible in the attached assessment and review sources.

## L6 Timed
Mix with adjacent families without hints.

## L7 Cumulative Transfer
Recognize the method in an unfamiliar source-supported construction.

# Common Errors

Misrecognition; an invalid first decision; arithmetic or algebra execution errors; omitted restrictions; incomplete answer form.

# Professor Traps

Source-observed risks include distributing a negative sign incorrectly, clearing only some denominators, dividing by a variable expression without a restriction, and failing to identify no-solution or all-real-number outcomes.

# Professor-Style Templates

1. A minimally guided symbolic linear equations prompt with the method unstated.
2. A linear equations representation bridge that changes notation or context while preserving the same first decision.
3. A cumulative linear equations prompt with one prerequisite and the required final-form check.

# Feedback Rules

Give recognition feedback first, then a bounded first-decision cue. Do not reveal the full solution before controlled retries.

# Expected Answer Presentation

Present a solution value or solution set, with checks required by the original operations.

# Mastery Rule

Require three surface constructions, representation transfer where applicable, hint-free professor-style success, delayed success, no critical check errors, and a cumulative prerequisite problem.
