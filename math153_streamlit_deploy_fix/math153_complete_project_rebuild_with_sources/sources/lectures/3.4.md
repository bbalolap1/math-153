# 3.4 --- Functions

## Page 1 --- Definition

Formally, a function (f) from a set (D) to a set (E) assigns to each
element (x) of (D) exactly one element (y) of (E): \[
`\boxed{f:D\to E}`{=tex}. \]

Informally, a function is a rule that assigns every valid input a unique
output.

The collection of valid inputs is the **domain**.

## Page 2 --- Range

The collection of all possible outputs is the **range**.

Example: a function assigning each human being their birth date.

-   Domain: all valid human inputs.
-   Range: the collection of possible birth dates.

## Page 3 --- Domain and Range

For \[ f(x)=x\^2, \] domain: \[ `\boxed{(-\infty,\infty)}`{=tex} \] and
range: \[ `\boxed{[0,\infty)}`{=tex}. \]

For \[ `\frac{\sqrt{4+x}}{1-x}`{=tex}, \] require \[ x`\ge-4`{=tex} \]
and \[ x`\ne1`{=tex}. \]

Therefore: \[ `\boxed{[-4,1)\cup(1,\infty)}`{=tex}. \]

## Page 7 --- Increasing, Decreasing, Constant

Increasing on interval (I): \[
`\boxed{f(x_1)<f(x_2)\text{ whenever }x_1<x_2}`{=tex}. \]

Decreasing: \[ `\boxed{f(x_1)>f(x_2)\text{ whenever }x_1<x_2}`{=tex}. \]

Constant: \[ `\boxed{f(x_1)=f(x_2)}`{=tex}. \]

Handwritten interpretations: - increasing: bigger inputs = bigger
outputs; - decreasing: bigger inputs = smaller outputs; - constant:
flat/horizontal graph.

## Page 9 --- Difference Quotient

For points with inputs (x) and (x+h), the secant-line slope is \[
`\frac{f(x+h)-f(x)}{(x+h)-x}`{=tex}. \]

Since the denominator simplifies to (h): \[
`\boxed{\frac{f(x+h)-f(x)}{h}}`{=tex}. \]

This is the **difference quotient**.

## Page 10 --- Difference Quotient Example

Given \[ f(x)=x\^2+6x-4, \] find \[ `\frac{f(x+h)-f(x)}{h}`{=tex}. \]

Substitute: \[ `\frac{(x+h)^2+6(x+h)-4-(x^2+6x-4)}{h}`{=tex}. \]

Expand and cancel: \[ `\frac{2xh+h^2+6h}{h}`{=tex}. \]

Factor: \[ `\frac{h(2x+h+6)}{h}`{=tex}. \]

Therefore: \[ `\boxed{2x+h+6}`{=tex}. \]
