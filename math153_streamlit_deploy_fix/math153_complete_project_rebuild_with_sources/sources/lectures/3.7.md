## Operations on Functions

We can add, subtract, multiply, and divide functions.

\[ (f+g)(x)=f(x)+g(x) \]

\[ (f-g)(x)=f(x)-g(x) \]

\[ (fg)(x)=f(x)g(x) \]

\[
`\left`{=tex}(`\frac{f}{g}`{=tex}`\right`{=tex})(x)=`\frac{f(x)}{g(x)}`{=tex}
\]

For the first three operations, the domain of the new function is

\[
`\operatorname{dom}`{=tex}(f)`\cap`{=tex}`\operatorname{dom}`{=tex}(g).
\]

\[ f(x)=`\sqrt{x+1}`{=tex},`\qquad `{=tex}g(x)=`\frac{1}{2x}`{=tex}. \]

\[ (f+g)(x)=`\sqrt{x+1}`{=tex}+`\frac1{2x}`{=tex}
=`\frac{2x\sqrt{x+1}+1}{2x}`{=tex}. \]

\[ (f-g)(x)=`\sqrt{x+1}`{=tex}-`\frac1{2x}`{=tex}
=`\frac{2x\sqrt{x+1}-1}{2x}`{=tex}. \]

\[ (fg)(x)=`\sqrt{x+1}`{=tex}`\frac1{2x}`{=tex}
=`\frac{\sqrt{x+1}}{2x}`{=tex}. \]

Because (x+1`\ge0`{=tex}) and (x`\ne0`{=tex}),

\[ `\boxed{[-1,0)\cup(0,\infty)}`{=tex}. \]

## Composite Functions / Compositions

A composition applies two function rules back-to-back.

\[ `\boxed{(f\circ g)(x)=f(g(x))}`{=tex}. \]

The process is

\[ x`\longrightarrow `{=tex}g(x)`\longrightarrow `{=tex}f(g(x)). \]

### Example

\[ f(x)=x\^2-1,`\qquad `{=tex}g(x)=3x+5. \]

\[ (f`\circ `{=tex}g)(x)=f(3x+5) =(3x+5)\^2-1 \]

\[ =9x\^2+30x+25-1 \]

\[ `\boxed{(f\circ g)(x)=9x^2+30x+24}`{=tex}. \]

\[
`\operatorname{dom}`{=tex}(f`\circ `{=tex}g)`\subseteq`{=tex}`\operatorname{dom}`{=tex}(g).
\]
