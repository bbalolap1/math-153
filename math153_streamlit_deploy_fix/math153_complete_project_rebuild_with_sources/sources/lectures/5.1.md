# 5.1 - Inverse Functions

## One-to-One Functions

A function

\[ f:D`\to `{=tex}R \]

is one-to-one if

\[ `\boxed{f(x_1)=f(x_2)\Rightarrow x_1=x_2}`{=tex}. \]

Equivalent idea: different inputs always give different outputs; each
output comes from only one input.

### Example

\[ f(x)=3x+2. \]

Assume

\[ f(x_1)=f(x_2). \]

Then

\[ 3x_1+2=3x_2+2 \]

\[ 3x_1=3x_2 \]

\[ `\boxed{x_1=x_2}`{=tex}. \]

So (f) is one-to-one.

For

\[ g(x)=x\^2-3, \]

\[ g(1)=1\^2-3=-2 \]

and

\[ g(-1)=(-1)\^2-3=-2. \]

Different inputs give the same output, so

\[ `\boxed{g\text{ is not one-to-one}}`{=tex}. \]

## Horizontal Line Test

A graph represents a one-to-one function if every horizontal line
intersects it at most once.

The source shows an increasing curve that passes the horizontal line
test and a wavy graph that fails it.

For

\[ f(x)=3x+2, \]

the line passes the horizontal line test.

For

\[ g(x)=x\^2-3, \]

the parabola fails the horizontal line test.

## Inverses

If

\[ f:D`\to `{=tex}R \]

is one-to-one, then it admits an inverse

\[ f\^{-1}:R`\to `{=tex}D. \]

The inverse satisfies

\[ `\boxed{(f\circ f^{-1})(x)=x}`{=tex} \]

and

\[ `\boxed{(f^{-1}\circ f)(x)=x}`{=tex}. \]

The domain of (f\^{-1}) is the range of (f).

The range of (f\^{-1}) is the domain of (f).

The inverse "undoes" what the original function does.

## Verifying Inverses

\[ f(x)=3x-5,`\qquad `{=tex}g(x)=`\frac{x+5}{3}`{=tex}. \]

\[ (f`\circ `{=tex}g)(x)
=3`\left`{=tex}(`\frac{x+5}{3}`{=tex}`\right`{=tex})-5 =x. \]

\[ (g`\circ `{=tex}f)(x) =`\frac{(3x-5)+5}{3}`{=tex} =x. \]

Therefore (g=f\^{-1}).

## Finding an Inverse Algebraically

Find (f\^{-1}(x)) for

\[ f(x)=`\frac{3x+4}{2x-4}`{=tex}. \]

Start with

\[ y=`\frac{3x+4}{2x-4}`{=tex}. \]

Swap (x) and (y):

\[ x=`\frac{3y+4}{2y-4}`{=tex}. \]

Solve for (y):

\[ x(2y-4)=3y+4 \]

\[ 2xy-4x=3y+4 \]

\[ 2xy-3y=4x+4 \]

\[ (2x-3)y=4x+4 \]

\[ `\boxed{f^{-1}(x)=\frac{4x+4}{2x-3}}`{=tex}. \]

## Restricted Quadratic

\[ f(x)=x\^2-3,`\qquad `{=tex}x`\ge0`{=tex}. \]

Because the domain is restricted to (x`\ge0`{=tex}), the function is
one-to-one.

Swap (x) and (y):

\[ y=x\^2-3 \]

\[ x=y\^2-3 \]

\[ y=`\sqrt{x+3}`{=tex}. \]

Therefore

\[ `\boxed{f^{-1}(x)=\sqrt{x+3}}`{=tex}. \]

The graphs of a function and its inverse are reflections across

\[ `\boxed{y=x}`{=tex}. \]
