# 5.2 - Exponential Functions

## Definition

Compare a power function

\[ f(x)=x\^n \]

with an exponential function

\[ `\boxed{f(x)=b^x}`{=tex}, \]

where

\[ b\>0,`\qquad `{=tex}b`\ne1`{=tex}. \]

If

\[ 0\<b\<1, \]

the function is decreasing: **exponential decay**.

If

\[ b\>1, \]

the function is increasing: **exponential growth**.

In either case, (b\^x) is one-to-one.

The horizontal asymptote shown in the notes is

\[ `\boxed{y=0}`{=tex}. \]

## Solving Equal-Base Exponential Equations

Find all real solutions:

\[ 7^{3x}=7^{2x+5}. \]

Since (7\^x) is one-to-one,

\[ 3x=2x+5 \]

so

\[ `\boxed{x=5}`{=tex}. \]

## Finding an Exponential Function

Find

\[ f(x)=ab\^{-x}+c \]

with horizontal asymptote (y=-2), (y)-intercept (16), and (x)-intercept
(2).

Horizontal asymptote:

\[ `\boxed{c=-2}`{=tex}. \]

Thus

\[ f(x)=ab\^{-x}-2. \]

Using the (y)-intercept:

\[ f(0)=a-2=16 \]

so

\[ `\boxed{a=18}`{=tex}. \]

Using the (x)-intercept (x=2):

\[ 18b\^{-2}-2=0 \]

\[ b\^{-2}=`\frac19`{=tex} \]

\[ b\^2=9 \]

and, since an exponential base is positive,

\[ `\boxed{b=3}`{=tex}. \]

Therefore

\[ `\boxed{f(x)=18(3)^{-x}-2}`{=tex}. \]

## Compound Interest

\[ `\boxed{A=P\left(1+\frac rn\right)^{nt}}`{=tex} \]

where:

-   \(P\) = principal
-   \(r\) = annual interest rate as a decimal
-   \(t\) = number of years invested
-   \(A\) = amount after (t) years
-   \(n\) = number of compounding periods per year

## Minimum-Wage Exponential Model

In 1938 the minimum wage was \$0.25/hour. By 1997 it was \$5.15/hour.

Let

\[ f(t)=ab\^t, \]

where (t=0) corresponds to 1938.

Then

\[ a=0.25. \]

Since 1997 is (59) years after 1938,

\[ 5.15=0.25b\^{59}. \]

Therefore

\[ 20.6=b\^{59} \]

and

\[ b=`\sqrt[59]{20.6}`{=tex}`\approx1.053`{=tex}. \]

So the model in the notes is

\[ `\boxed{f(t)\approx0.25(1.053)^t}`{=tex}. \]
