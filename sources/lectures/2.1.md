## Page 1 --- What Is an Equation?

An equation is something of the form

\[ `\text{one expression}`{=tex}=`\text{another expression}`{=tex} \]

It is a **statement of equality**.

The expressions are typically algebraic.

Example:

\[ x\^2-5=4x \]

This is a quadratic equation.

The **solutions/roots** of an equation are numbers that can be
substituted for the variables and make the equation true.

Equations are divided into three classes based on their solution sets.

------------------------------------------------------------------------

## Page 2 --- Identity, Conditional, and Contradiction Equations

### Identity

An equation is an **identity** if it is true for every value in its
domain.

Examples:

\[ x+3=x+3 \]

\[ `\frac5{x-1}`{=tex}=`\frac5{x-1}`{=tex},`\qquad `{=tex}x`\ne1`{=tex}
\]

These reduce to a (0=0)-type statement.

### Conditional equation

An equation is **conditional** if it is true only for some values in its
domain.

Examples:

\[ x+3=1 `\Rightarrow `{=tex}x=-2 \]

\[ `\frac5{x-1}`{=tex}=1 `\Rightarrow `{=tex}x=6 \]

\[ x\^2+y=1 `\Rightarrow `{=tex}y=1-x\^2 \]

These are (x=`\text{value}`{=tex})-type equations.

### Contradiction

An equation is a **contradiction** if it is not true for any value in
its domain.

Examples include equations reducing to impossible statements.

------------------------------------------------------------------------

## Page 3 --- Equivalent Equations

Equations are **equivalent** if they have exactly the same solution
sets.

For example,

\[ x=0,`\qquad `{=tex}2x=0,`\qquad `{=tex}x\^2=0 \]

all have the same solution (x=0), so they are equivalent.

By contrast,

\[ x=1,`\qquad `{=tex}2x=1,`\qquad `{=tex}x\^2=1 \]

do not all have the same solution set.

### Solve

\[ 6x-7=2x+5 \]

\[ 6x=2x+12 \]

\[ 6x-2x=12 \]

\[ 4x=12 \]

\[ `\boxed{x=3}`{=tex} \]

Each line is an equivalent equation.

## Page 5 --- Factoring and Rational Equations

### Solve

\[ x\^2-16=0 \]

\[ x\^2=16 \]

\[ x=`\pm`{=tex}`\sqrt{16}`{=tex} \]

\[ `\boxed{x=4\text{ or }x=-4}`{=tex} \]

Using factoring:

\[ x\^2-16=(x-4)(x+4) \]

\[ (x-4)(x+4)=0 \]

so one factor must equal zero.

### Solve

\[ `\frac1{x+4}`{=tex}+`\frac3{x-4}`{=tex} = `\frac{3x+8}{x^2-16}`{=tex}
\]

Domain:

\[ x`\ne4`{=tex},-4 \]

Factor:

\[ x\^2-16=(x+4)(x-4) \]

Multiply through by the common denominator:

\[ x-4+3(x+4)=3x+8 \]

\[ x+8=8 \]

\[ `\boxed{x=0}`{=tex} \]

## Page 6 --- Recognizing an Identity

Determine the type of equation:

\[ (4x-3)^2-16x^2=9-24x \]

Use

\[ (a+b)^2=a^2+2ab+b\^2 \]

to expand:

\[ (4x-3)^2=16x^2-24x+9 \]

Then:

\[ 16x^2-24x+9-16x^2=9-24x \]

Both sides reduce to the same expression:

\[ 0=0 \]

Therefore the equation is an **identity**.

------------------------------------------------------------------------

## Page 7 --- Another Identity

Determine the type of equation:

\[ `\frac{3x^2+8}{x}`{=tex} = `\frac`{=tex}8x+3x \]

Domain:

\[ x`\ne0`{=tex} \]

Left side:

\[ `\frac{3x^2+8}{x}`{=tex} = `\frac{3x^2}{x}`{=tex}+`\frac`{=tex}8x =
3x+`\frac`{=tex}8x \]

Right side:

\[ `\frac`{=tex}8x+3x \]

The expressions are equal throughout the domain, so this is an identity
for

\[ x`\ne0`{=tex}. \]

------------------------------------------------------------------------

## Page 8 --- Are These Equations Equivalent?

Compare:

\[ `\frac{8x}{x-7}`{=tex} = `\frac{72}{x-7}`{=tex} \]

with

\[ x-3=6 \]

For the rational equation:

\[ x`\ne7`{=tex} \]

Multiply by (x-7):

\[ 8x=72 \]

\[ `\boxed{x=9}`{=tex} \]

The second equation also gives

\[ x-3=6`\Rightarrow`{=tex}`\boxed{x=9}`{=tex} \]

So the two equations have the same solution set.

------------------------------------------------------------------------

## Page 9 --- Domain Can Change Equivalence

Compare:

\[ `\frac{8x}{x-7}`{=tex} = `\frac{56}{x-7}`{=tex} \]

with

\[ 2x-4=10 \]

The rational equation has domain

\[ x`\ne7`{=tex}. \]

Algebraically multiplying by (x-7) gives

\[ 8x=56 \]

\[ x=7 \]

but (x=7) is excluded from the original equation's domain, so the
rational equation is a **contradiction / has no valid solution**.

The second equation gives

\[ 2x-4=10 \]

\[ 2x=14 \]

\[ x=7 \]

Thus these equations are **not equivalent**.
